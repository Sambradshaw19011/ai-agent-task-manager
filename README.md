# AI Agent Task Manager

A simple task management web application built with the assistance of an
AI coding agent. The project demonstrates how an `AGENTS.md` file can
give an AI coding agent clear project instructions, coding guidelines,
and development expectations.

## Features

The planned core features are:

-   Create tasks with a title and description.
-   View a list of tasks.
-   Edit existing tasks.
-   Mark tasks as complete or incomplete.
-   Delete tasks.

Possible future enhancements include task priorities and categories.

## Instructions for Build and Use

### Build and run the software

1.  Install [Node.js](https://nodejs.org/) and npm.

2.  Clone this repository:

    ``` bash
    git clone <your-public-repository-url>
    ```

3.  Change into the project directory:

    ``` bash
    cd ai-agent-task-manager
    ```

4.  Install the project dependencies:

    ``` bash
    npm install
    ```

5.  Start the development server:

    ``` bash
    npm run dev
    ```

6.  Open the local URL printed in the terminal.

> **Note:** These commands assume the project uses Node.js and has the
> relevant scripts configured in `package.json`. If the project uses a
> different framework or start command, update these instructions to
> match the actual project setup.

### Use the software

1.  Open the application in your browser.
2.  Create a task by entering its title and description.
3.  View your tasks in the task list.
4.  Edit a task or mark it complete/incomplete as needed.
5.  Delete tasks that you no longer need.

The exact interface and available actions may change as development
progresses.
